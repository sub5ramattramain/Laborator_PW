# dashboard proiecte

o aplicatie full-stack pentru gestionarea si urmarirea statusului proiectelor. permite operatiuni complete de tip crud (creare, citire, actualizare, stergere) si ofera statistici in timp real din baza de date.

## tehnologii folosite

* react (frontend)
* node.js si express (backend)
* mongodb si mongoose (baza de date)

## instalare si pornire

asigura-te ca ai instalat node.js si ca serviciul mongodb ruleaza pe calculatorul tau (pe portul 27017).

### 1. pornire backend (server)
deschide un terminal in folderul serverului si ruleaza urmatoarele comenzi:

```bash
npm install
node index.js
```

### 2. pornire frontend (client)
deschide un terminal separat in folderul aplicatiei react si ruleaza:

```bash
npm install
npm run dev
```
aplicatia se va deschide in browser pe portul specificat (de obicei http://localhost:5173).
